# BATI
Bryairs Actually Thinking Intelligence is a GOFAI model of AI that aims to get a flexible symbolic artificial intelligence as an alternative to generative artificial intelligence in some scenarios. Distributed versions of BATI must be open source in all areas except Addons, which can stay private. 

# Updates
BATI is expected to first get released (v.01) around in january 2027. C++ is still being learned 

# Why?
BATI is being made because of generative AI. Since this is just made by one guy still in high school, it will not come anywhere close to replacing generative AI. However, it is being made for my needs of models not hallucinating and running faster since it would run on Central Processing Units and not Graphical Processing Units.

# Versions
There will be 2 separate versions, one as a chatbot and another to run inside of simulations. In the future, the simulation will have its own repo for people who want to fork it while the AI itself stays here.
