# BATI
Bryairs Actually Thinking Intelligence is a GOFAI model of AI that aims to get a flexible symbolic artificial intelligence as an alternative to generative artificial intelligence in some scenarios. Distributed versions of BATI must be open source in all areas except Addons, which can stay private.
